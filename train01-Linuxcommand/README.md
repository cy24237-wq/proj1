# 小問題1 Linuxコマンド演習

## 目的

Linuxの基本コマンド、リダイレクト、パイプ、標準出力・標準エラー出力の仕組みを理解する。

---

## 問題1：ファイル一覧を保存する

### コマンド

```bash
ls > out
```

### 解説

`ls` は現在のディレクトリ内のファイル一覧を表示するコマンドである。

通常は画面（標準出力）に表示されるが、`>` を使用すると出力結果をファイルへ保存できる。

この例では、ファイル一覧を `out` というファイルに保存している。

---

## 問題2：保存した内容を確認する

### コマンド

```bash
cat out
```

### 解説

`cat` コマンドはファイルの内容を表示する。

先ほど作成した `out` の内容を確認できる。

---

## 問題3：/usr/bin 内に cat が存在するか確認する

### コマンド

```bash
ls /usr/bin > out2
grep cat out2
```

### 解説

`ls /usr/bin` を実行すると大量のファイルが表示されるため、一度 `out2` に保存する。

その後、

```bash
grep cat out2
```

を実行し、`cat` という文字列を検索する。

`grep` は文字列検索を行うコマンドである。

---

## 問題4：パイプを利用して検索する

### コマンド

```bash
ls /usr/bin | grep cat
```

### 解説

`|`（パイプ）は前のコマンドの出力を次のコマンドの入力として渡す。

この例では、

```text
ls /usr/bin
↓
grep cat
```

という流れで処理が行われる。

一時ファイルを作成せずに検索できる。

---

## 問題5：エラーも含めて保存する

### コマンド

```bash
ls out out2 out3 > allout 2>&1
```

### 解説

`out` と `out2` は存在するが、`out3` は存在しないためエラーが発生する。

Linuxには以下の3つの標準入出力が存在する。

| ファイル記述子 | 内容      |
| ------- | ------- |
| 0       | 標準入力    |
| 1       | 標準出力    |
| 2       | 標準エラー出力 |

通常、

```bash
ls out out2 out3
```

を実行すると、

成功した結果は標準出力へ、

```text
out
out2
```

エラーメッセージは標準エラー出力へ送られる。

`2>&1` は

「標準エラー出力を標準出力と同じ場所へ送る」

という意味である。

そのため `allout` には成功結果とエラーの両方が保存される。

---

## 学んだ内容

* `ls` ：ファイル一覧表示
* `cat` ：ファイル内容表示
* `grep` ：文字列検索
* `>` ：標準出力をファイルへ保存
* `|` ：パイプ
* `2>` ：標準エラー出力を保存
* `2>&1` ：標準出力と標準エラー出力を統合
* ファイル記述子 0・1・2 の意味
