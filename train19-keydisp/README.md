# 第2回提出課題 keydisp.c

## 目的

GPIO22番に接続された茶ボタンを押したときに、LCDの上の行に `hello` と表示し、ボタンを離してから1秒経過したら表示を消すプログラムを作成する。

---

# 動作概要

このプログラムでは、GPIO22番の値を読み取り、茶ボタンが押されているか離されているかを判定する。

ボタンが押されたらLCD上段に `hello` を表示する。

ボタンが離されたことを検出したら、タイマーを開始する。

そのタイマーが1秒後に発火したら、メインループ内でLCD表示を消去する。

---

# 重要な注意点

## タイマーを開始するタイミング

タイマーは、ボタンが離されたことを検出してから開始する。

つまり、

```text
最後に押されていることを検出した時点
```

ではなく、

```text
押されている状態から離された状態に変化した時点
```

から1秒を測定する。

---

## シグナルハンドラ内でLCD制御をしない理由

LCD制御では、コマンド送信後に数ms待つなどの時間制御が必要になる。

タイマーのシグナルは、LCDへコマンドを送っている途中など、微妙なタイミングで発生する可能性がある。

そのため、シグナルハンドラの中でLCD制御を行うと、LCDの動作が不安定になる可能性がある。

したがって、シグナルハンドラではグローバル変数に値を代入するだけにする。

実際のLCD制御はメインループで行う。

---

# 検出方法

## GPIO22の読み取り

GPIO0番からGPIO31番までの状態は、1つの整数値として読み取ることができる。

その中からGPIO22番だけを調べるために、ビット演算を使う。

```c
value & (1 << 22)
```

この式により、GPIO22番のビットだけを確認できる。

---

# ボタンが押されているか離されているかの判定

GPIO22番の値を読み取り、押したときと離したときの値を比較する。

例として、以下のように判定する。

```c
if (value & (1 << 22)) {
    /* GPIO22が1 */
} else {
    /* GPIO22が0 */
}
```

実際の回路によって、

```text
押したとき → 1
離したとき → 0
```

の場合もあれば、

```text
押したとき → 0
離したとき → 1
```

の場合もある。

授業環境で確認した値に合わせて判定する。

---

# 押されたことの判定

現在のボタン状態と、1回前のボタン状態を比較する。

```text
前回：離されている
今回：押されている
```

になったとき、ボタンが押されたと判定する。

---

# 離されたことの判定

```text
前回：押されている
今回：離されている
```

になったとき、ボタンが離されたと判定する。

このタイミングで1秒タイマーを開始する。

---

# 「離してから1秒経ったら消す」の実現方法

ボタンが離されたことを検出したら、`setitimer()` を使って1秒後に1回だけ発火するタイマーを設定する。

```c
timer.it_value.tv_sec = 1;
timer.it_value.tv_usec = 0;

timer.it_interval.tv_sec = 0;
timer.it_interval.tv_usec = 0;
```

`it_value` は最初にタイマーが発火するまでの時間である。

`it_interval` を0にすると、繰り返しではなく1回だけ発火するタイマーになる。

---

# シグナルハンドラ

タイマーが発火すると `SIGALRM` が発生する。

そのとき、シグナルハンドラではLCDを直接操作せず、グローバル変数だけを変更する。

```c
volatile sig_atomic_t clear_flag = 0;

void timer_handler(int signum)
{
    clear_flag = 1;
}
```

---

# メインループでのLCD消去

メインループ内で `clear_flag` を確認する。

```c
if (clear_flag) {
    clear_flag = 0;
    clear_lcd();
}
```

このようにすることで、LCD制御を安全にメイン処理側で行う。

---

# LCDへの表示

LCDに文字を表示するには、`lcd_datawrite()` を使用する。

文字列は1文字ずつ送る。

```c
lcd_datawrite('h');
lcd_datawrite('e');
lcd_datawrite('l');
lcd_datawrite('l');
lcd_datawrite('o');
```

または、文字列をループで1文字ずつ送る。

---

# LCDの消去

LCDの消去には、`lcd_cmdwrite()` でClear Display命令を送る。

```c
lcd_cmdwrite(0x01);
```

または、余力問題を行う場合は、空白文字を表示して消す方法も使える。

---

# プログラムの基本構成

```text
初期化
↓
GPIO22を読む
↓
押されたら hello 表示
↓
離されたら1秒タイマー開始
↓
タイマー発火
↓
clear_flag を立てる
↓
メインループでLCD消去
```

---

# 使用する主な関数

| 関数                 | 役割            |
| ------------------ | ------------- |
| memread()          | GPIOレジスタを読む   |
| lcd_datawrite()    | LCDに文字を書く     |
| lcd_cmdwrite()     | LCDに命令を送る     |
| location()         | LCDの表示位置を変更する |
| setitimer()        | タイマーを設定する     |
| signal()           | シグナルハンドラを登録する |
| sleep() / usleep() | 待機する          |

# keydisp.c の考え方

## ボタン状態

```c
int now_button;
int prev_button;
```

`now_button` に現在の状態を入れる。

`prev_button` に1回前の状態を入れる。

この2つを比較して、押された瞬間と離された瞬間を判定する。

---

## 押された瞬間

```c
if (prev_button == 0 && now_button == 1) {
    display_hello();
}
```

---

## 離された瞬間

```c
if (prev_button == 1 && now_button == 0) {
    start_timer();
}
```

---

# 余力問題1

1秒経つ前にまたボタンが押された場合は、表示を消さない。

そのため、再度押されたときにタイマーを止める、または `clear_flag` を無効にする処理を追加する。

最後に離された時点から1秒後に消すようにする。

---

# 余力問題2

赤ボタンGPIO23番を使う。

* 茶ボタン GPIO22 → 上の行に `hello`
* 赤ボタン GPIO23 → 下の行に `world`

それぞれ独立して動作させる。

表示位置の変更には `location()` を使う。

```c
location(0, 0);
```

上の行

```c
location(0, 1);
```

# 開発環境の工夫

作成したプログラムは、何度も実行してGPIOの値を確認しながら調整した。

特に、ボタンを押した状態と離した状態でGPIO22番の値がどのように変化するかを確認し、その結果に合わせて押下判定を行った。

また、シグナルハンドラ内ではLCD制御を行わず、グローバル変数だけを変更するようにして、機器制御が不安定にならないように工夫した。
